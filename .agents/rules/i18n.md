# Textos e idiomas

- Ningún texto visible en el código: todo con `t('ui.…')` o `t('content.…')`.
- Toda clave nueva se agrega en `en.json`, `es.json` y `pt.json` en el mismo cambio, con las mismas variables `{{...}}`.
- Español neutro con tuteo; portugués de Brasil con «você». Términos de `src/i18n/GLOSSARY.md` (en portugués, «casa» para el espacio entre trastes).
- Plurales de i18next con `_one` / `_other` en los 3 idiomas.
- Botones de 28 caracteres o menos en los 3 idiomas.
- Verifica con `npm run check:i18n`. Procedimiento completo: skill `i18n-sync`.
